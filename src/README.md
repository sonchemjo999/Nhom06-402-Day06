# Source Code

## Structure
- **app_config**: Cấu hình ứng dụng (settings, themes, datetime)
- **ui**: Giao diện người dùng (KV files, styles, icons)
- **core**: Logic chính (AI agent, admin commands, utilities)
- **services**: Services (sound manager, notifications)
- **assets**: Tài nguyên (icons, sounds, data)

## Main Entry Point
`main.py` - Khởi động ứng dụng
