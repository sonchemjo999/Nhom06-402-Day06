### Chi tiết các tầng xử lý ảnh

```
image_utils.preprocess_prescription_image()
  Load(RGB) → Grayscale → Auto-Denoise →
  Contrast(×1.6) → Brightness(×1.05) →
  Deskew(Hough) → AdaptiveThreshold(31,5) →
  Sharpen → Resize(900×1200)

get_quality_score() → 0.0–1.0
  < 0.4: "⚠️ Ảnh chất lượng thấp"
  0.4–0.7: "⚡ Ảnh chất lượng trung bình"
  > 0.7: "✅ Ảnh chất lượng tốt"
```
